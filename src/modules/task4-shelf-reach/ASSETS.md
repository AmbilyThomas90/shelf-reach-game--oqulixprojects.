# Assets used by Task 4 - Shelf Reach

The game works with no files at all (it falls back to built-in vector art and
synthesized sounds). To upgrade the look and sound, drop real files into
`src/modules/task4-shelf-reach/assets/`. They are found by **file name**;
sub-folders are fine.

| File name (any of .png .jpg .webp .svg) | Used for                          |
|-----------------------------------------|-----------------------------------|
| `background`                            | Full-screen kitchen / pantry wall |
| `shelf`                                 | Shelf board (stretched)           |
| `counter`                               | Countertop and grocery cabinet    |
| `cereal`, `juice`, `soup`, `honey`      | The four pantry items             |
| `character`                             | Mascot standing on the counter    |

| File name (.mp3 .ogg .wav) | Used for                     |
|----------------------------|------------------------------|
| `pickup`                   | Grabbing an item             |
| `place`                    | Item snapping onto a shelf   |
| `combo`                    | 3+ items in a row            |
| `levelup`                  | New level                    |
| `complete`                 | Session finished             |
| `music`                    | Looping background music     |
